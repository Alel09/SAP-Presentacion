Concepto

¿Qué es el Modo Libre?

  • Sintaxis flexible: no exige punto y coma ni declarar tipos.
  • Enfoque en la lógica: menos errores de forma, más pensamiento algorítmico.
  • Puente a otros lenguajes: ideal antes de Python, C++ o Java.
Comparativa

Modo estricto vs Modo libre

🔒 Modo estricto

  • Exige punto y coma
  • Requiere declarar variables
  • Un solo símbolo de asignación

🔓 Modo libre

  • Punto y coma opcional
  • Variables sin declarar
  • Acepta <- o =

Del diagrama al pseudocódigo

Un bucle, dos formas de verlo

Algoritmo Suma
  suma = 0
  Para i = 1 Hasta 3 Hacer
    suma = suma + i
    Escribir suma
  FinPara
  Escribir "Total: ", suma
FinAlgoritmo
flowchart TD
  A([Inicio]):::fin --> B["suma = 0 · i = 1"]:::proc
  B --> C{"i <= 3 ?"}:::dec
  C -- Sí --> D["suma = suma + i"]:::proc
  D --> E[/"Escribir suma"/]:::io
  E --> F["i = i + 1"]:::proc
  F --> C
  C -- No --> G[/"Escribir total"/]:::io
  G --> H([Fin]):::fin
